# cosmobench

**cosmobench** — Benchmark harness measuring whether agent skills (cosmoskill, thcosmoskill) improve LLM answers in cosmology

It measures whether agent skill packages (cosmoskill, thcosmoskill) change the
accuracy and cost of a model's answers on cosmology questions, by running the
same questions under several arms and grading the answers. It is for the
maintainers of those skill packages, as the check before a release.
